6.1 Irrevocability

Transfers submitted through the Vektes Protocol are irrevocable by the sender once confirmed on-chain. There is no chargeback, cancellation, or reversal mechanism available to senders. You acknowledge this is a core design feature, not a defect.

6.2 Recipient Rejection

Recipients may reject pending (unsettled) transfers, which returns funds to the sender. This is the only mechanism by which a transfer can be reversed, and it is solely at the recipient's discretion.

6.3 Settlement Dates

Funds locked with a future settlement date cannot be accessed by the recipient until that date passes. The Protocol enforces this programmatically. Neither we nor any third party can accelerate or modify settlement dates.

6.4 Transaction Codes

Each transaction code is unique per sender-recipient pair. Once used, a code cannot be reused for the same pair. Ensure you use meaningful, unique codes for each transfer.
